Política de privacidade

Esta página apresenta a Skill Edição Dinâmica, de Liniker Wambaster. Aqui explicamos que dados são coletados e para quê.

O que coletamos

  • Dados de navegação: páginas vistas, quanto do vídeo foi assistido e cliques nos botões de compra.
  • Parâmetros do anúncio que trouxe você até aqui (por exemplo utm_source e fbclid).
  • Endereço IP e navegador, enviados à Meta para medir os anúncios.

Não coletamos nome, e-mail ou telefone nesta página. Os dados da compra são tratados pela plataforma de pagamento.

Para que usamos

Para medir o resultado dos anúncios e mostrar anúncios para quem já demonstrou interesse, usando o Pixel da Meta e a API de Conversões.
