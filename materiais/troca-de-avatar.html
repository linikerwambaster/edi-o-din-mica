A skill da troca de avatar com IA

Você grava um vídeo seu e o Claude Code devolve o mesmo vídeo com uma personagem de IA no seu lugar: mesmo cenário, mesmos movimentos, mesmo tempo. Com a tela dividida sincronizada pronta pra postar.

Em cima: euEmbaixo: IA
Baixar a skill grátis ZIP · 20 KB

Funciona no Claude Code (app do Claude, aba Code, ou terminal), no Windows e no Mac.

Como instalar

Baixe o ZIP e extraia. Dentro tem a pasta troca-de-avatar-ia e o LEIA-ME.md.
Copie a pasta para C:\Users\seu-usuario\.claude\skills\ (Windows) ou ~/.claude/skills/ (Mac). Se a pasta skills não existir, crie.
Abra uma conversa nova no Claude Code e mande: "Quero fazer a trend da troca de avatar com o vídeo X e a imagem Y." Ele te guia no resto, inclusive no Google Flow.

O que você precisa

  • Claude Code instalado.
  • Conta Google com acesso ao Google Flow. Cada trecho de ~9 s usa créditos do seu plano Google.
  • ffmpeg e Python (os comandos de instalação estão no LEIA-ME).
  • Uma imagem de personagem criada por IA. Nunca use o rosto de uma pessoa real.

Quer editar seus vídeos assim, com motion e efeitos?

A troca de avatar é só uma parte. Com a skill Edição Dinâmica, o Claude Code corta, anima e coloca efeitos sonoros nos seus vídeos, no padrão dos reels que eu posto.
